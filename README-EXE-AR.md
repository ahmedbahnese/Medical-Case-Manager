# Medical Case Manager — إصدار Windows مع قاعدة محلية

تم تجهيز المشروع ليعمل كتطبيق سطح مكتب Windows عبر Electron، مع استخدام SQLite مدمجة بدل PostgreSQL. لا يحتاج المستخدم إلى تثبيت PostgreSQL أو تشغيل خادم منفصل.

## الملفات الناتجة

| الملف | الاستخدام |
|---|---|
| `BSCH-Setup-1.0.0.exe` | مثبت Windows ينشئ اختصارًا في سطح المكتب وقائمة Start. |
| `BSCH-Portable-1.0.0.exe` | نسخة محمولة يمكن تشغيلها مباشرة دون تثبيت. |

## البيانات المحلية

يُنشأ ملف قاعدة البيانات تلقائيًا داخل مجلد بيانات المستخدم في Windows، غالبًا في:

```text
%APPDATA%\BSCH\bsch.sqlite
```

ويتم تفعيل وضع WAL لتحسين الاعتمادية. لا تحذف هذا الملف إذا كنت تريد الاحتفاظ بالحالات والإعدادات.

## التشغيل

شغّل المثبت `BSCH-Setup-1.0.0.exe`، ثم افتح التطبيق من الاختصار. يبدأ التطبيق الخادم المحلي تلقائيًا ويفتح الواجهة داخل نافذة مستقلة. النسخة المحمولة تعمل بالطريقة نفسها.

## البناء من المصدر

من جذر المشروع:

```bash
pnpm install
pnpm run build:prod
cd electron
npm install
npm run build-win
```

توجد الملفات الناتجة داخل `electron/dist-electron/`. يتطلب بناء Windows من Linux وجود Wine، بينما يمكن البناء مباشرة على Windows دون Wine.

## ملاحظات مهمة

تم الحفاظ على واجهات API والحقول الحالية، مع نقل مخططات Drizzle إلى SQLite. كلمة مرور الدخول الافتراضية الموروثة من المشروع هي `bsch2024`، ويُنصح بتغييرها من إعدادات النظام بعد أول تشغيل.

تم اختبار فحص TypeScript وبناء الخادم والواجهة، كما تم التحقق من تهيئة ملف SQLite وتشغيل الخادم المحلي. اختبار واجهة Electron النهائي يجب أن يتم على جهاز Windows فعلي.
