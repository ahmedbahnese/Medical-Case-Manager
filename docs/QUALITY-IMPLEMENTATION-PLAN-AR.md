# خطة تنفيذ وحدات الجودة والسلامة

## النطاق

سيتم تنفيذ الوحدات الأربع داخل البنية الحالية دون إعادة بناء التطبيق: **OVR، Quality Management، CAPA، وQuality Dashboard**. ستُستخدم جداول SQLite الحالية للمرضى (`medical_cases`)، الأقسام (`departments`)، وسجل العمليات (`audit_logs`) مع إضافة الحد الأدنى من الجداول اللازمة.

## الصلاحيات

بما أن النسخة الحالية تستخدم جلسات المؤسس ومستخدمين مسمّين بدل جدول مستخدمين مستقل، ستتم إضافة صلاحية `Quality Manager` إلى إعدادات النظام مع قائمة حسابات ممنوحة. سيُطبّق التحقق في Backend/API، وليس في الواجهة فقط. المستخدم العادي ينشئ OVR ويراه ضمن بلاغاته فقط، بينما المؤسس ومدير الجودة يديران المراجعة والتحقيق وCAPA والتقارير.

## نموذج البيانات

ستضاف جداول `ovr_reports` و`quality_investigations` و`capa_records` و`quality_risks` و`quality_audits` و`quality_indicators` و`quality_notifications`، إضافة إلى إعدادات التصنيفات والأنواع. ستُحفظ المرفقات بصيغة JSON داخل السجل في الإصدار الأول لتبقى متوافقة مع تخزين التطبيق الحالي، مع التحقق من الحجم والنوع.

## التوافق مع Windows 7 ‏x32

سيظل Electron على الإصدار 22.3.27؛ فالإصدار 22 هو آخر خط رئيسي يدعم Windows 7/8/8.1، لذلك لن تتم ترقية Electron إلى 23 أو أحدث في هذا الإصدار. سيُبنى هدف `ia32` فقط للنسخة النهائية منخفضة الموارد، مع إبقاء هدف `x64` اختياريًا عند الحاجة. كما ستُتجنب واجهات Node الحديثة غير الضرورية داخل مشغل التحديث.

> ملاحظة تشغيلية: دعم Windows 7 في Electron 22 هو توافق تقني قديم، وليس دعمًا أمنيًا مستمرًا من فريق Electron. يجب اختبار النسخة على جهاز Windows 7 فعلي قبل التوزيع.

## التحديث دون إعادة التثبيت

ستُضاف آلية تحديث داخل مجلد بيانات المستخدم، لا داخل مجلد التثبيت المحمي. سيقرأ التطبيق ملف `update-manifest.json` من مجلد إعدادات المؤسسة، ويقارن الإصدار، ثم ينفذ تحديثًا ذريًا عبر مجلد مؤقت ونسخة احتياطية تلقائية. ستبقى قاعدة البيانات في `app.getPath('userData')` ولن تُحذف عند التحديث. في حال فشل التحديث يعاد تشغيل النسخة السابقة تلقائيًا.

## التسليم المرحلي

سيُرفع كل تغيير منطقي في commit مستقل إلى الفرع ثم إلى GitHub، مع تشغيل فحص TypeScript وبناء الواجهة والخادم قبل إنشاء النسخة التنفيذية. سيتم إنشاء Release نهائي يحتوي على مثبت `ia32` ونسخة Portable وملف تعليمات التحديث.
