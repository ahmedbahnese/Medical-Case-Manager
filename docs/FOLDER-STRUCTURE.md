## Key Conventions

| Convention | Detail |
|-----------|--------|
| **Port** | API server always on `PORT` env var (default 8080) |
| **Auth** | Session cookie (`bsch_session`), signed with `SESSION_SECRET` |
| **DB access** | Only via `lib/db` — never direct SQL in routes except db-init.ts |
| **API calls** | Frontend uses `apiGet/apiPost/apiPatch/apiDelete` helpers in `lib/api.ts` |
| **Toasts** | Always use `toast` from `sonner`, never `useToast` from Radix |
| **Audit log** | Every create/update/delete route calls `logAction()` |
| **No `.returning()`** | MySQL doesn't support it — routes use `$returningId()` + SELECT |
